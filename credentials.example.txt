# Exemple de fichier d'identifiants pour check_fameswap_login.mjs
# Copiez ce fichier en "credentials.txt" et remplacez par vos vraies valeurs.
# Les lignes vides et celles commençant par # sont ignorées.
#
# --- Format le plus simple : 2 lignes (identifiant puis mot de passe) ---
mon.email@exemple.com
monMotDePasse
#
# --- Autres formats acceptés (au choix, un seul à la fois) ---
#
# Format étiqueté :
#   email = mon.email@exemple.com
#   password = monMotDePasse
#
# Ou avec un nom d'utilisateur :
#   username = monPseudo
#   password = monMotDePasse
#
# Format une ligne :
#   mon.email@exemple.com:monMotDePasse
