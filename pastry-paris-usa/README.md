# Pastry Paris → USA

Kit complet pour repositionner un compte sur la niche **pâtisserie parisienne**, à partir
des vidéos d'un pâtissier réputé de Paris, et les republier vers une **audience américaine**.

## Ce qu'il y a dedans

| Dossier | Contenu |
|---|---|
| `00-strategie/` | Positionnement US, réponse à la question « 40 s → 1 min », réglages de reposting |
| `01-scripts/` | 6 scripts vidéo complets (hook, beat sheet, VO EN, textes à l'écran, CTA) |
| `02-hooks/` | Banque de 40 hooks testables + la formule pour en écrire d'autres |
| `03-production/` | Recettes ffmpeg, checklist de publication, plan de test |
| `04-droits/` | Accord avec le pâtissier + message type (FR/EN) |

## Règle n°1 du repost vers les US

Un repost brut (même vidéo, même son, même texte) est plafonné par les plateformes et
n'est pas éligible aux programmes de rémunération. Ce qui passe, c'est la **transformation** :
nouvelle VO en anglais, nouveau montage, nouveaux textes à l'écran, nouveau hook, durée > 1 min.
Tous les scripts d'ici sont construits pour ça.

## Boucle de travail

1. Recevoir le rush du pâtissier (40–60 s brut).
2. Choisir un script dans `01-scripts/` (ou l'adapter avec un hook de `02-hooks/`).
3. Monter selon le beat sheet → cible **1:05 – 1:15**.
4. Passer la checklist `03-production/checklist-publication.md`.
5. Publier sur les créneaux US, logger le résultat dans `03-production/plan-de-test.md`.
